# Chill Party V0.2.4

- Default UI language: Traditional Chinese
- One-time language hint on first load
- Increased BGM volume
- Keeps V0.2.1 audio system, home button, and party modes


## V0.2.4 changes
- Each game mode, including Mix Party, supports a custom round count from 1 to 100.
- BGM gain increased from 100% baseline to 150%.


## V0.2.4
- Draw & Guess adds a Hide/Show Word button beside the prompt.
- Hidden prompts always display exactly `xxxxx`, regardless of the answer length.
- The word is shown again automatically at the start of each new drawing round.
